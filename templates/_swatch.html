{# ── Amostras de cor (swatch + donut) — ÚNICA fonte para todo o app ────────── `swatch()`: quadradinho de 12px usado nas listas/busca/fila de etiquetas. `donut()`: anel SVG de % restante (spools/filamentos, big + pequeno). Os dois recebem o hex CRU e aplicam `hexcolor` internamente — quem chama nunca sanitiza na mão. `translucent=true` desenha um xadrez (checkerboard, padrão global `#sc-checker` definido em base.html) sob a cor em opacidade parcial, em vez de uma cor sólida — um "Transparent" (#FFFFFF) some de Branco e ganha um padrão de transparência, com o tom (se houver) ainda visível por cima. Nenhum recurso externo; funciona nos dois temas via tokens de `static/spool.css` (--sc-surface/--sc-border). Contorno fino nas bordas do anel (`.donut-outline`, preto no claro/branco no escuro) para o rolo preto não sumir no tema escuro. #} {% macro swatch(hex, translucent=false, size=12, hex2='') %} {% set c2 = hex2 | hexcolor('') %} {% endmacro %} {% macro donut(pct, fill, translucent=false, spool_id='', size=34, tip='', fill2='') %} {% set c1 = fill | hexcolor('#6c757d') %} {% set c2 = fill2 | hexcolor('') %} {% set gid = 'sc-dual-' ~ (c1 | replace('#', '')) ~ '-' ~ (c2 | replace('#', '')) %} {% endmacro %}
